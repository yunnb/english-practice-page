# Sentz | 나만의 영어 작문 연습 플랫폼

## 📝 프로젝트 소개
Sentz는 사용자가 영어 글쓰기 실력을 키울 수 있도록 지원하는 웹 애플리케이션입니다.

## 🛠 기술 스택

### Front-end
- **React**
- **JavaScript**
- **styled-components**

### Back-end
- **Node.js**
- **MySQL**

## 💡 주요 기능

1. **영작 연습** 
    > 사용자가 작성한 문장을 확인하여 정확한 문법과 단어 사용을 제공합니다.
    > 학습 내용을 기록하고, 마지막 복습 일자와 복습 횟수를 확인할 수 있습니다.
